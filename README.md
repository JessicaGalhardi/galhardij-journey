## 🇬🇧 English

### 🚀 Project Overview
This project is a premium, single-page interactive CV and portfolio designed to break away from traditional resume constraints. It serves as an authentic cultural filter and a showcase of technical and artistic capabilities, combining advanced front-end effects with custom generative AI artwork.

### ✨ Key Features
* **Immersive Parallax Scrolling:** Multi-layered depth effects that create a dynamic and engaging visual storytelling experience upon scroll.
* **AI-Driven Visual Identity:** Custom-curated hero graphics and section images crafted using original prompts via **Gemini, ChatGPT, and Lovable**, featuring a unique Studio Ghibli-inspired and "Tech-Chic" aesthetic.
* **Multilingual Support:** Seamless toggling between English (EN), Italian(IT), Spanish(SP) and Portuguese (PT).
* **Interactive Storytelling Map:** A rich, detailed conceptual map illustrating my international professional journey bridging Brazil and Italy.
* **Atmospheric Soundtrack:** Built-in ambient background music (audio toggle) sourced from Pixabay (by OpenMindAudio) to elevate the user experience.
* **ATS-Optimized CV Download:** Clean, professional PDF resume downloads integrated directly into the interface.

### 🛠️ Tech Stack & Tools
* **Frontend:** HTML5, CSS3 (Advanced custom properties & parallax layouts), JavaScript (ES6+) / React
* **Build Tools & Platforms:** VS Code, Lovable, Vite, Netlify (Hosting & Deployment)
* **Generative AI Tools:** Gemini & ChatGPT (Art direction, copywriting, and prompt engineering)
* **Audio:** OpenMindAudio via Pixabay Music

## 🇧🇷 Português

### 🚀 Visão Geral do Projeto
Este projeto é um currículo interativo de página única (*one-page*) premium, desenvolvido para ir além dos limites de um currículo tradicional. Ele funciona como um filtro cultural autêntico e uma vitrine de capacidades técnicas e artísticas, combinando efeitos avançados de front-end com artes personalizadas geradas por Inteligência Artificial.

### ✨ Funcionalidades Chave
* **Efeito Parallax Imersivo:** Camadas de profundidade que criam uma experiência de narrativa visual dinâmica e envolvente durante a rolagem da página.
* **Identidade Visual Guiada por IA:** Elementos gráficos principais e imagens de seção criados por meio de prompts originais no **Gemini, ChatGPT e Lovable**, trazendo uma estética inspirada no Studio Ghibli e um tom "Tech-Chic".
* **Suporte Multilíngue:** Alternância fluida entre Inglês (EN), Italiano(IT), Espanhol(ES) e Português (PT).
* **Mapa de Storytelling Interativo:** Um mapa conceitual rico e detalhado que ilustra minha trajetória profissional internacional entre o Brasil e a Itália.
* **Trilha Sonora Atmosférica:** Reprodutor de música ambiente integrado (com botão liga/desliga) com áudio do Pixabay (por OpenMindAudio) para enriquecer a experiência do usuário.
* **Download de CV Otimizado para ATS:** Integração de botões para baixar o currículo em PDF em um formato limpo, direto e otimizado para sistemas de recrutamento.

### 🛠️ Tecnologias e Ferramentas
* **Frontend:** HTML5, CSS3 (Propriedades personalizadas avançadas e layouts parallax), JavaScript (ES6+) / React
* **Ferramentas de Build e Deploy:** VS Code, Lovable, Vite, Netlify (Hospedagem e Deploy)
* **Inteligência Artificial Generativa:** Gemini e ChatGPT (Direção de arte, redação de conteúdo e engenharia de prompts)
* **Áudio:** OpenMindAudio via Pixabay Music
